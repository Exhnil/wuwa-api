The backend API for **Wuthering Waves Planner**, a fan-made tool dedicated to [Wuthering Waves](https://wutheringwaves.kurogames.com/).

## Overview

This API primarily serves the frontend by providing access to game-related data and images used throughout the application.

## Getting Started

Clone the repository and install the dependencies:

```bash
git clone https://github.com/Exhnil/wuwa-api.git
cd wuwa-api
npm install
```

Start the server:

```bash
npm start
```

## Tech Stack

- **Node.js** — JavaScript runtime
- **Express** — Web application framework
